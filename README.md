# 图书管理系统

## 一、项目简介

本项目是《高级语言程序设计》课程设计大作业，旨在使用 C++ 面向对象程序设计思想，设计并实现一个图书管理系统。

系统主要面向图书馆管理员和普通用户，实现图书信息管理、图书查询、图书借阅、图书归还、库存管理以及用户账号管理等功能。

项目采用类与对象、封装、继承、多态以及多文件编程等技术，提高程序的模块化程度和可扩展性。

---

## 二、项目目标

本项目主要实现以下目标：

- 实现图书信息的统一管理
- 实现图书查询
- 实现图书借阅与归还
- 实现图书库存管理
- 实现图书分类管理
- 实现用户注册与登录
- 区分管理员和普通用户的操作权限
- 实现系统数据的文件存储
- 使用继承和多态构建合理的类体系
- 采用多文件方式组织程序

---

## 三、主要功能

### 1. 用户管理

#### 普通用户

- 用户注册
- 用户登录
- 查询图书
- 借阅图书
- 归还图书
- 查看个人借阅记录

#### 管理员

- 管理用户信息
- 添加图书
- 删除图书
- 修改图书信息
- 查询图书
- 查看库存信息
- 查看借阅记录

---

### 2. 图书管理

系统支持对图书进行统一管理。

主要功能包括：

- 添加图书
- 删除图书
- 修改图书信息
- 查询图书
- 按类别查询
- 查看全部图书
- 查看图书库存

---

### 3. 图书借阅

普通用户可以查询并借阅可借图书。

借阅成功后，系统自动更新图书库存，并生成相应的借阅记录。

---

### 4. 图书归还

用户可以归还已经借阅的图书。

归还后：

- 更新图书库存
- 更新借阅记录
- 判断是否逾期

---

### 5. 逾期管理

系统记录：

- 借阅时间
- 应归还时间
- 实际归还时间

系统可以根据借阅记录判断图书是否逾期，并进行相应提醒。

---

## 四、系统角色

系统主要包含两种用户：

| 用户类型 | 主要权限 |
| -------- | -------- |
| 普通用户 | 查询、借阅、归还、查看借阅记录 |
| 管理员 | 图书管理、用户管理、库存管理、借阅记录管理 |
